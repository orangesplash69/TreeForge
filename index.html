Tips

          
    
            
  • While renaming, type app.js # entry point to attach a note. Notes line up as comments in the output.
    • 
            
  • Type a path such as src/lib/util.js to create the missing folders in one go. End a name with / to turn it into a folder.
    • 
            
  • Import understands tree output (including Windows), indented and Markdown lists, plain path lists and JSON (including tree -J).
    • 
            
  • Drop a folder anywhere on the page to read its structure. Nothing is uploaded.
    • 
            
  • Your work is saved in this browser automatically. Use Export → Copy share link to send a tree to someone — the whole tree lives inside the link.
